This is a fork of the official iNaturalist React Native app. It is *not* maintained or supported by the official iNaturalist team. It's just me, an amateur birder, poking around and adding some features I wanted. If you want to try it out, feel free, but expect bugs, and please don't complain to the official iNaturalist team about it - they didn't write this.

New Features:
- Cropping and adjusting the brightness of images
- Improvements for bulk observation import
- Map scale indicator
- Explore search with multiple taxa
- Named saved filters
- Life list view in explore for your new species
- Animal audio ID tool, similar to Merlin, based on BirdNET model
- Many more

If you want to try it out, join the open beta on TestFlight: https://testflight.apple.com/join/XXDSpREq

For now, this is iOS only.
